# فازهای بعدی (اسکلت — بدون کد تا تأیید نسخه اول)

این سند فقط برنامه‌ریزی است. پیاده‌سازی پس از تأیید صریح پایان نسخه اول و گفتگوی جدا.

## ۴) نامه اداری

- ورودی: درخواست زبان طبیعی یا فرم ساختاریافته
- خروجی: پیش‌نویس نامه + گردش تأیید (نقش‌محور پس از نهایی شدن جدول دسترسی)
- ارسال: پنل + بات
- API جدا برای ایجاد/خواندن/تأیید نامه

## ۵) جدول دسترسی نهایی

منبع: بریف بند ۶ — **پیش‌نویس تا تأیید مالک**.

نقش‌های پیشنهادی (تغییر بدون تأیید ممنوع):

- مدیرعامل
- مدیر مالی
- مدیر فروش
- کارمند فروش
- کارمند عادی
- ادمین سیستم

تا آن زمان فقط نقش `admin` در v0.

## ۶) دفترچه تعریف مفاهیم

- نگاشت فیلدهای خام سپیدار/سایت به مفاهیم: هزینه، سود، درآمد، …
- هر عدد داشبورد باید به تعریف دفترچه وصل شود
- تا آن زمان خروجی مالی برچسب «منبع + فیلد خام» دارد (فاز ۲ همین را رعایت می‌کند)

## وابستگی‌های بیرونی باقی‌مانده

- توکن بات تلگرام و/یا بله
- تأیید نهایی نقش‌ها
- در صورت نیاز: دسترسی IP سرور داخلی به پنل ادمین maahed.ir
